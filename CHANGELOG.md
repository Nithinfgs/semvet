# Changelog

## 0.1.0

First release.

- Compiler-driven API comparison using assignability witnesses.
- Generic-aware checks (signatures re-checked with opaque probe types).
- Drill-down from a failing type to the members that changed.
- Enum value changes, removed members, union widening/narrowing.
- Package-level rules: removed subpath exports, removed bins, module type, minimum Node.
- Baselines from npm, git refs, directories and tarballs.
- Output as text, JSON, Markdown and GitHub annotations; composite GitHub Action.
- Worker-thread execution with chunking, bisection and skip-with-warning for pathological symbols.
