# Launch drafts

Drafts only. Nothing here has been posted anywhere. Post them yourself, in your own voice, and edit freely.
Reply to every comment in the first few hours; honest answers about the limits do more than any copy.

Rules of thumb:

- Post one place at a time, a day or two apart, not everywhere at once.
- Lead with the problem and a concrete example, not the tool.
- Say what it does *not* catch. People trust that.
- Never ask for stars. Ask for the two-snippet bug report.

Files: `hacker-news.md`, `reddit.md`, `x-twitter.md`, `linkedin.md`, `github-metadata.md`.
